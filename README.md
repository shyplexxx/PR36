# 📌 МДК 11.01 - ПР32-40

### 🛠️ Схемы импорта базы данных
* **`db_S`** — содержит **только структуру** базы данных (таблицы, связи, триггеры без самих записей).
* **`db_DS`** — полный дамп, включающий **структуру + данные** (все заполненные строки таблиц).

---

### 📂 Организация файлов (33ПР)
* Все файлы импорта и готовые дампы для **33ПР** необходимо сохранять строго в целевую папку **`ff`**.

---

### 📦 Инструменты для резервного копирования (MySQL)
Для реализации автоматического создания дампов не забудьте установить один из пакетов через **NuGet Package Manager** (выбирайте в зависимости от используемого драйвера):

* **Вариант 1 (Для стандартного драйвера):**
  ```bash
  Install-Package MySqlBackup.NET
  ```
* **Вариант 2 (Для оптимизированного драйвера):**
  ```bash
  Install-Package MySqlBackup.NET.MySqlConnector
  ```
